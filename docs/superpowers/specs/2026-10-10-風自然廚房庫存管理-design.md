# 風自然廚房庫存管理 — 設計文件

日期：2026-10-10
類型：單機單檔網頁（早餐店廚房庫存管理）

## 目標

提供早餐店廚房一個離線可用的庫存管理網頁。以手機操作為主，能快速調整庫存、看出哪些品項需要補貨，並一鍵產生可傳到 LINE 的補貨清單、下載 Word 檔或列印。資料存於瀏覽器，可匯出 JSON 帶到另一台電腦還原。

## 硬性限制

- 單一 `index.html`，CSS 與 JavaScript 全部內嵌，不需伺服器、無外部依賴（離線可用）。
- 手機優先：按鈕大、字大，支援深色模式。
- 資料存 `localStorage`，所有存取包 `try/catch`。
- 介面全繁體中文。

## 資料模型

localStorage key：`fzkf-inventory-v1`（專案前綴 `fzkf-`）。
theme 設定 key：`fzkf-theme`。

```json
{
  "version": 1,
  "categories": [
    { "id": "c1", "name": "炸物", "icon": "🍟" }
  ],
  "items": [
    {
      "id": "i1",
      "categoryId": "c1",
      "name": "耐炸油",
      "unit": "桶",
      "stock": 0,
      "target": 1,
      "note": "一定要叫",
      "estTarget": true
    }
  ]
}
```

- `stock`：目前庫存，非負，0.5 的倍數。
- `target`：應備量，非負，0.5 的倍數。
- `estTarget`：應備量是否為「暫估」。
- 首次啟動無資料 → 載入範例資料。
- 讀寫失敗 → 顯示紅色提示訊息（toast），不中斷操作。

## 需補計算

`need = max(0, target - stock)`

- `need > 0`：顯示紅色「需補 N 單位」。
- `need == 0`：顯示綠色「足夠」。
- 頁籤上的紅色徽章 = 該分類需補品項數；「補貨清單」頁籤徽章 = 全部需補品項數。

## 版面

### 頂部標題列
- 標題「風自然廚房庫存管理」。
- ⚙️ 設定按鈕，展開選單：
  - 新增分類（名稱＋圖示欄位，預設 📦）
  - 調整分類順序（開啟排序頁，見下方）
  - 還原範例資料（確認框）
  - 匯出 JSON
  - 匯入 JSON
  - 複製 Markdown
- 深色模式切換：預設跟隨系統 `prefers-color-scheme`，可手動切換並記於 `fzkf-theme`。

### 主頁籤列
- 可左右滑動、吸頂。
- 「📦 全部品項」在最左側且為預設頁，之後為「📋 補貨清單」（顯示全站需補數紅色徽章）。
- 舊有的「分類頁籤」已移除，改由全部品項頁的分類區塊與快捷標籤呈現。

### 全部品項頁（主畫面）
- 最上方為「分類快捷標籤列」：每個分類一個標籤（圖示＋名稱），**點一下**捲動到該分類區塊。
- 下方依分類分成多個區塊，每區塊：
  - 標題列（圖示＋名稱）吸頂；右側有 `↑`、`↓`（調整分類順序）與 ✏️（編輯該分類：改名／改圖示／刪除）。
  - 區塊底部有「＋ 新增品項」（可直接在此新增，分類預設帶入）。
  - 每個品項一列：品名、狀態（需補／足夠，含暫估徽章），右側兩組操作：**庫存** 與 **應備** 各為 `－ [數字] ＋`。
  - **長按品項列約 0.5 秒**可開啟該品項的編輯視窗。
- 分類順序調整：⚙️ 設定 →「⇅ 調整分類順序」，開啟專屬頁面；每列為 `[↑] 圖示 名稱 [↓]`（↑ 在左、↓ 在右，按鈕 56px 好按），可連點快速移動，第一列 ↑、最後列 ↓ 變灰。改的是一份暫存順序，按「完成」才寫回 `state.categories` 並重繪（「取消」丟棄）。標籤列與區塊順序同步。
- 同一頁支援**長按拖曳**：長按整列約 0.25 秒後該列**反白浮起**（橘色外框＋陰影＋微放大），上下拖動時其他列即時讓位；放開即固定。手機以 touch 事件（`passive:false`）＋長按後才 `preventDefault` 解決捲動衝突，長按前若先滑動超過 10px 則取消長按（讓清單正常捲動）；桌機支援滑鼠拖曳。拖曳只改暫存順序，仍須按「完成」才套用。
- 不用進編輯視窗，往下滑即可把全部庫存與應備量設定完。

### 品項編輯視窗
- 由分類區塊「＋ 新增品項」，或**在全部品項頁長按品項列約 0.5 秒**開啟。長按前若先滑動超過 10px 會取消（讓頁面正常捲動）；桌機支援滑鼠長按。品項列上長按後會震動一下作為回饋。
- **新增模式**：品名欄可一次輸入多個名稱，以 `.` `-` `－` `、` `。` 或換行分隔（例：`麵條.米飯.米粉`），一次在該分類建立多個品項；單位／目前庫存／應備量／備註／暫估設定會套用到這批新品的每一個（庫存、應備預設 0，可留空）。
- **編輯模式**：品名為單一名稱（不分割）；欄位：品名、分類、單位、目前庫存、應備量、備註、暫估勾選、刪除鈕。
- 庫存／應備值限定 0.5 倍數；點欄位全選、步進 1、不可低於 0（詳見下方規則）。

### 分類管理
- 新增分類：⚙️ 設定的「新增分類」。
- 編輯／刪除分類：於全部品項頁該分類標題列按 ✏️，於視窗內改名、改圖示或刪除；刪除時確認框提示「將連同 N 個品項一起刪除」。
- **批次勾選刪除品項**：編輯分類視窗下方列出該分類所有品項＋勾選框，可逐項勾選或「全選」，按「刪除已選 (N)」一次刪除（N=0 時按鈕變灰）；確認框「確定刪除已選的 N 個品項嗎？」。

### 預設資料與版本升級
- 內建範例資料（含「🍚 柴米油鹽醬醋茶」38 項常見廚房材料）為首次開啟的預設值。
- 以 `state.dataVersion` 記錄資料版本（`DATA_VERSION`）；開啟時若存檔版本較舊，**一次性**把新版預設品項補進對應分類（依「分類＋品名」去重，不覆蓋既有），補完記錄版本；之後使用者刪除的品項不會再被自動加回。
- 共用清單常數 `KITCHEN_STAPLES` 同時供 `seed()` 與版本升級使用，避免兩處不同步。

### 補貨清單頁
- 依分類分組輸出補貨文字，只列需補品項。
- 無需補時顯示「目前沒有需要補貨的品項」。
- 按鈕：複製清單、分享到 LINE、下載 Word 檔、列印。

## LINE 補貨清單文字格式

```
📋 補貨清單
📅 10/10（週六）

━━━━━━━━━━
🍟 炸物
━━━━━━━━━━
▫️ 耐炸油　補 1 桶（一定要叫）
▫️ 雞塊　補 11 包（常用，缺很多）

━━━━━━━━━━
🥟 蒸包
━━━━━━━━━━
▫️ 燒賣　補 2 盒

✅ 共 3 項待補
```

規則：
- 分類標題前放該分類圖示。
- 品項前放 `▫️`。
- 品名與數量間用全形空格。
- 備註放括號內，空備註則省略括號。
- 日期格式 `M/D（週X）`。
- 最後一行 `✅ 共 N 項待補`。

## 分享與輸入輸出

- **複製清單**：`navigator.clipboard.writeText`，成功顯示「已複製」。
- **分享到 LINE**：優先 `navigator.share({ text })`；不支援則自動複製並提示「此裝置不支援分享，已幫你複製」。
- **下載 Word 檔**：HTML 內容轉 `.doc`（Blob，`application/msword`），補貨清單緊湊排版、盡量單頁，檔名 `補貨清單-YYYYMMDD.doc`。（真正 `.docx` 需 zip 程式庫，離線單檔不可行，故用 `.doc`。）
- **檔案輸出跨裝置策略**：手機（含 iPhone Safari）優先使用系統分享 `navigator.share({ files })`（可「儲存到檔案」或轉傳 LINE／郵件）；桌機使用 `<a download>` 直接下載。若該裝置兩者皆不可用，JSON 匯出改以彈窗顯示內容供「一鍵複製」保存。此策略同時套用於 JSON 匯出與 Word 下載。
- **列印**：`window.print()`，`@media print` 隱藏所有 UI，只留純白底黑字補貨清單，字級與間距壓縮，盡量一頁。
- **匯出 JSON**：下載 `風自然廚房庫存-YYYYMMDD.json`，內容為完整資料。
- **匯入 JSON**：選擇檔案 → 確認框「將覆蓋目前所有資料」→ 解析驗證後寫入並重繪。
- **複製 Markdown**：產生全分類清單（含庫存／應備／需補）之 Markdown 供純觀看備份（不支援 Markdown 上傳還原）。
- **還原範例資料**：確認後重置為內建範例。

## 錯誤處理

- localStorage 存取一律 try/catch；失敗顯示紅色 toast。
- JSON 匯入：解析失敗、格式不符 → 顯示錯誤並保留原資料。
- 所有破壞性操作（刪分類、刪品項、還原、匯入）皆需確認框。

## 驗收重點

- 全部分類與品項能正確顯示與調整庫存。
- 需補／足夠狀態與頁籤徽章數字正確。
- LINE 文字格式與範例一致（含全形空格、圖示、括號備註、總項數）。
- 複製／分享／下載 Word／列印皆可用；列印與 Word 只含補貨清單。
- 匯出 JSON 後匯入能 100% 還原。
- 深色模式正常、離線可用、無 console 錯誤。
