# 風自然廚房庫存管理 — 盤點頁設計

日期：2026-10-31
類型：單機單檔網頁（`index.html`）新增功能

## 目的

提供一個「邊走邊清點」的介面：一次看到所有分類與所有品項，逐項輸入目前實際庫存，
最後按一次套用，把數字寫回正式庫存欄，補貨清單即時反映新的待補數量。

現有「全部品項」頁維持不動，盤點頁是獨立分頁。

## 入口與導航

主分頁列改為三個：

1. 📦 全部品項（預設）
2. 📋 補貨清單
3. 📝 盤點（新增）

盤點分頁在草稿有變更時，右上角顯示橘色數字徽章（變更品項數）。

## 版面

- 頂部分類 chips（水平滑動），點擊跳到該分類區塊。
- 分類標題橫跨整列並 sticky。
- 品項以 CSS Grid 排列：
  `grid-template-columns: repeat(auto-fill, minmax(148px, 1fr))`
  - 手機（375–430px）：2 欄
  - 平板／橫向（640px 容器）：4 欄
- 每個格子（tile）內容：
  - 品名（最多兩行，超出省略）
  - 單位（小字）
  - 數字輸入框（整格寬、`inputmode="decimal"`、點擊全選）
- 已修改的格子：橘色外框＋「已改」提示；未修改維持一般樣式。
- 底部固定操作列：
  - 「清除盤點」（次要按鈕）
  - 「套用盤點結果 (N)」（主要按鈕，N=0 時停用）
- 頁尾保留 spacer，避免固定列遮住最後一列品項。

## 資料流

### 草稿

- 獨立存放於 `localStorage`，key：`fzkf-stocktake-draft`
- 格式：`{ "version": 1, "values": { "<itemId>": <number> }, "updatedAt": <ISO string> }`
- 草稿不寫入 `state`、不包含在 JSON 匯出中。
- 輸入時即時更新草稿；切換分頁、重新整理都會保留。
- 讀取時忽略不存在的 itemId（品項已被刪除）。

### 套用

1. 讀取畫面上所有 `data-role="count"` 輸入框的值。
2. 空白輸入視為「未變更」，不套用（避免誤清成 0）。
3. 以 `parseQty` 正規化：負數轉 0、四捨五入到 0.5 倍數。
4. 只把與目前 `stock` 不同的品項寫回 `state.items[].stock`。
5. 有變更才跳確認框：「將套用 N 項盤點結果，覆蓋目前庫存，確定嗎？」
6. 確認後：`save()` → 清空草稿 → 重繪 → toast「已更新 N 項庫存」。
7. 留在盤點頁，不自動跳轉。

補貨清單沿用 `need = max(0, target - stock)`，套用後自動反映，無需修改。

### 清除盤點

- 確認後清空草稿，所有輸入恢復成目前庫存。

### 邊界情況

- 輸入框清空並離開欄位 → 自動還原成目前庫存，不算變更。
- 非 0.5 倍數 → 離開欄位時正規化顯示。
- 盤點期間新增品項 → 顯示目前庫存。
- 盤點期間刪除品項 → 草稿自動忽略。
- 執行「還原範例資料」或「匯入 JSON」→ 一併清除草稿。

## 不改動範圍

- 「全部品項」頁、「補貨清單」頁。
- 資料結構、`state.version`、JSON 匯出／匯入格式。
- 深色模式與既有樣式變數。

## 驗證清單

- 三個分頁可正常切換。
- 手機 2 欄、平板 4 欄排列。
- 點輸入框會全選，輸入後格子變橘色、徽章與按鈕數字同步。
- 重整後草稿仍在；切到別頁再回來草稿仍在。
- 套用後庫存更新、草稿清除、補貨清單數量改變。
- 清除盤點後輸入恢復原庫存。
- 空白欄位不會把庫存歸零。
- 刪除品項、還原資料、匯入 JSON 後草稿不會殘留錯誤資料。
